# student-performance-analysis


An exploratory and statistical analysis of secondary-school
mathematics performance using the UCI Student Performance Dataset.

## Project Overview

This project investigates demographic, family, behavioral, and
school-related factors associated with students' mathematics performance.

The dataset contains 395 students and 33 variables.

## Research Questions

1. Which factors best predict overall academic performance?
2. Do demographic factors affect performance?
3. Do students aspiring to higher education perform better?
4. Does parental education influence performance?
5. Does family background affect grades?

## Methods

- Exploratory Data Analysis
- Welch Two-Sample t-tests
- Spearman Correlation
- ANOVA & Tukey HSD
- Multiple Linear Regression
- Regression Diagnostics

## Key Findings

- Past failures were the strongest predictor of academic performance.
- Mother's education showed a positive association with grades.
- Going out more frequently showed a small negative association.
- Students aspiring to higher education had higher average grades.
- Family structure variables did not show statistically significant
  relationships with academic performance.
